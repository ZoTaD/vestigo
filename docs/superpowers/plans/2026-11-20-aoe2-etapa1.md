# AoE2 DE, etapa 1 (en vivo): plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** sección `/aoe2` en Vestigo con estética "Campo de batalla": Portada, Ranking, Jugador (perfil + historial +
funciones), Partida, Civilizaciones, Matchups y Mapas, alimentada por la API de World's Edge y una Action diaria.

**Architecture:** igual que Company of Heroes. Un área `Aoe2.tsx` con pestañas cargadas con `import()`; lo en vivo
pasa por una Netlify Function (`/api/aoe2/*`) que reutiliza el cliente de la API de Relic (misma familia de API); las
estadísticas las arma un colector Python diario que escribe JSON chicos en `games/aoe2/stats/`. Datos del juego
(civs, escudos, arte) salen de la instalación local con un script.

**Tech Stack:** Vite + React + TypeScript (vitest), Netlify Functions, Cloudflare Worker `api/` (D1), Python 3 (pytest, Pillow).

**Spec:** `docs/superpowers/specs/2026-11-20-aoe2-design.md` (leerlo entero antes de empezar).

## Global Constraints

- Todo en español (código, comentarios, commits). Commits escuetos: título + 2–4 viñetas, sin planes ni IDs.
- Rama `claude/aoe2-seccion`, worktree `.claude/worktrees/aoe2-seccion`. Nada a `main` ni push sin el OK de ZoTaD.
- Juego instalado en `C:\Program Files (x86)\Steam\steamapps\common\AoE2DE`; textos en inglés de `resources/en/...` y en
  español de `resources/mx/...`.
- API: `https://aoe-api.worldsedgelink.com/community/leaderboard/<endpoint>` con `title=age2`, sin login, sin CORS.
- Rankings: 3 RM 1v1, 4 RM equipos, 13 EW 1v1, 14 EW equipos, 1 DM 1v1, 2 DM equipos, 15–18 de mando (`CO_*`);
  los temporales (`RBW_*`, `POM_*`, 5 Battle Royale) sólo si devuelven filas.
- Paleta: fondo #0b0f14, paneles #121a23 / #18222e, líneas #24313f, texto #eef2f6, apagado #93a3b5, dorado #f0bf4c,
  verde #69d27f, rojo #f26b5b; colores de jugador #2d6cf0 #e23b30 #2fb04f #f2cf2d #2bc4c4 #9a49d6 #a0a0a0 #f08a24.
  Títulos Cinzel 700/900, resto Inter. Sin franjas ni bordes de color en tarjetas o filas.
- Civs siempre con su escudo (`civ_techtree/menu_techtree_<civ>.png`), nunca grabados ni bocetos.
- Bandas de ELO: `<1000`, `1000–1400`, `1400–1800`, `1800+`, `all`. "Muestra chica" con menos de 200 partidas.
- Jugador y partida sin prerender, `noindex`, fuera del sitemap. Partida: `/aoe2/matches/<id>?p=<profile_id>`.
- Reglas de rendimiento de `CLAUDE.md`: ≤ 250 pedidos, ≤ 200 imágenes, ≤ 3.000 nodos de DOM por página; `LazyRows`
  en listas de más de ~150 filas; imágenes de lista `loading="lazy"`, `decoding="async"` y tamaño fijo; datos nunca en
  el chunk de entrada; JSON importados enteros.
- UI sin misterios: encabezados en palabras, sin scroll horizontal en 1440, 1100, 1024, 920 y 375 px.
- RAM: el colector y los tests no cargan más de un día de partidas a la vez.

## Review Focus

1. **Jugador sin partidas o perfil inexistente** (`/aoe2/players/123`): página con "No encontramos ese jugador" o
   "Todavía no tiene partidas de ranking", nunca pantalla en blanco ni 502 crudo. Test en Task 3 y Task 5.
2. **Partidas con jugadores que abandonan, empates o resultados sin reportar** (`outcome`/`resulttype` distintos de
   0/1): se cuentan como "otro", no como derrota, y no entran al % de victorias. Test en Task 3 y Task 8.
3. **Civ nueva que la tabla de ids no conoce** (sale un DLC): se muestra con escudo genérico y su id, el colector la
   guarda como `civ_<id>`, nada se rompe. Test en Task 1 y Task 8.
4. **Partidas de equipo con alias repetidos o jugadores de IA / perfil -1**: los rivales y compañeros se agrupan por
   `profile_id`, la IA no cuenta. Test en Task 5.
5. **API lenta o caída**: el handler corta a los 7 s y la pestaña muestra "La API del juego no responde, probá en un
   rato" con botón Reintentar; el ranking prerenderizado no depende de ella. Test en Task 3.
